Inspect the score

Jaccard counts shared features. Cosine weights each feature by how often it appears and how rare it is across the pool.

Features driving the match

    Spaces are shown as ␣. Each value is one feature’s contribution to the cosine score. The list shows up to eight contributions.

    Why can changing the pool change the scores?

    Inverse document frequency is fitted on both the source and target texts in the selected pool. Changing that pool changes feature rarity and the distractors that compete for first place.

    Turn ranks into evaluation metrics

    Move the aligned match for each of four hypothetical queries. Recall@1 only changes when a match enters or leaves first place. MRR also changes when a match moves between lower ranks.

    Compare the held-out benchmark

    Recorded test results for TF-IDF and both XLM-R variants. Fine-tuned XLM-R leads on low-overlap Recall@1, while TF-IDF leads on high-overlap Recall@1.

    How to compare these numbers

    The 20 ordered directions come from five varieties. Within each direction, the notebook uses the 33rd and 67th percentiles of aligned pair overlap for the low and high cutoffs. The benchmark reports macro averages across directions. Low, medium and high are relative to each direction.

    TF-IDF uses character features. Zero-shot XLM-R uses a pretrained encoder. Fine-tuned XLM-R adapts that encoder to the aligned training pairs before held-out evaluation.
